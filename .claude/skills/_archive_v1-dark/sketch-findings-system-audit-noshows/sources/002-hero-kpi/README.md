# Sketch 002 — Hero KPI

## Design Question

Dans le stepped reveal retenu (sketch 001 variant C), la step 02 est le
moment de vérité : le praticien découvre combien il perd. Trois traitements
possibles pour maximiser l'impact tout en restant clinique/factuel.

## How to View

```bash
open .planning/sketches/002-hero-kpi/index.html
```

## Variants

- **A — Money build empilé (baseline)**
  Calcul ligne-à-ligne animé (créneaux × tarif × mois = total). Pédagogique,
  pose les prémisses, le praticien ne peut pas contester le chiffre final.
  Sobre et rigoureux.

- **B — Compteur animé + équivalents concrets**
  Le chiffre XXL s'incrémente à l'écran (0 → 42 380 €) comme un compteur.
  Puis 3 équivalents concrets : "une Dacia neuve / 12 mois de salaire pour
  votre assistante / 85 prothèses". Traduit l'abstraction financière en
  réalités tangibles. Risque : "émotionnel", moins clinique.

- **C — Split comparatif (votre cabinet vs top 10%)**
  Côte à côte en split-screen : "Votre cabinet perd 42 380 €" vs "Top 10%
  perd 6 200 €", avec un gap card noir en dessous : "Écart à combler :
  36 180 €". Contextualise la perte par rapport au meilleur possible —
  donne un target implicite.

## What to Look For

- **Crédibilité clinique** : le chiffre reste-t-il factuel ou bascule-t-il vers le marketing émotionnel ?
- **Impact émotionnel** : laquelle fait le plus "mal" sans passer pour manipulatrice ?
- **Actionabilité implicite** : C donne un objectif chiffré (combler 36 180 €). Les autres restent statiques.
- **Cohérence avec Apple Health** : A et C sont les plus cohérents avec l'univers médical sobre. B tire vers le dashboard "growth hacking".
- **Risque** : B peut passer pour forcé (équivalents "Dacia" / "85 prothèses" peuvent paraître racoleurs).
