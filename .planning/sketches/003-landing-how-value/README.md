# Sketch 003 — Landing How it works + Value prop + Score

## Design Question

Trois blocs à articuler :
1. **Comment ça marche** — 3 étapes tricolores (bleu → émeraude → orange)
2. **Ce que révèle votre audit** — 4 bullets checks émeraude
3. **Score cabinet 72/100** — jauge SVG circulaire signature

La question : comment les composer sans que ça devienne un mur vertical de 4 sections de plus ?

## How to View

```
open .planning/sketches/003-landing-how-value/index.html
```

## Variants

- **A — Stacked + side score** (reprise 1:1 `new_design_audit.html`) : 3 cards étapes empilées verticalement `max-w-sm`, puis section value split 2-col avec value list à gauche et score card à droite. Sobre, prévisible.

- **B — Inline 3-col + hero score** : 3 cards étapes côte à côte 3 colonnes `max-w-4xl` (collapse en mobile). Section value centrée avec **score card en hero** (au-dessus du H2) + value list centrée en-dessous. Le score devient l'accroche visuelle principale de la section value.

- **C — Timeline + floating pill** ★ : 3 étapes sous forme de **timeline verticale** avec pastilles numérotées colorées reliées par une ligne, chaque étape a titre + sous-texte descriptif. Section value avec le **score en pill compacte flottante** (horizontal, plus petit que la score card pleine) — l'accent est sur la liste de révélations, le score est un "teaser".

## What to Look For

- La progression 1 → 2 → 3 est-elle claire visuellement ?
- Le score card (A) vs score hero (B) vs pill (C) : laquelle respecte le mieux son rôle de "signature" ?
- Densité globale de la section : trop lourd ? trop aérien ?
- Cohérence avec le ton sobre/institutionnel validé sur 002 ?

## Decision

**Winner : C — Timeline + floating pill** (validé 2026-04-23).
