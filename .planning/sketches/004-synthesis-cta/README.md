# Sketch 004 — Synthesis + CTA

## Design Question

Dernière step du stepped reveal (06/06). La step 5 (sketch 003 winner A) a
affiché le score de façon clinique. Maintenant il faut convertir. Comment
structurer cette dernière page pour maximiser les prises de RDV Calendly ?

## How to View

```bash
open .planning/sketches/004-synthesis-cta/index.html
```

## Variants

- **A — Verdict card XXL noir centered**
  Card noire premium pleine largeur, 42 380 € en serif XXL, headline,
  explainer, CTA + reassurance ⏱🔒📎. Minimaliste, focus total sur le CTA.
  Risque : perte de contexte, le praticien peut avoir "oublié" ses chiffres.

- **B — Timeline récap + verdict card**
  Rappel structuré des 4 chiffres clés du rapport (42 380 € / jeudi / +0,8 pt
  / 54/100) en timeline verticale avec pastilles colorées, puis verdict noir
  en bas avec CTA. Accumulation cognitive avant conversion.

- **C — Split problème / solution côte à côte**
  Gauche (blanc) : "Ce que votre CSV révèle" — 4 signaux critiques en liste
  avec métriques rouges. Droite (noir) : "Ce que PerfIAmatic peut faire" —
  plan d'action 30 min décomposé en 4 items, puis CTA + reassurance. Mise
  en parallèle visuelle douleur/remède.

## What to Look For

- **Pression de conversion** : A = directe / B = par accumulation / C = par opposition
- **Cohérence clinique Apple Health** : A > C > B (B est le plus "timeline storytelling", moins médical)
- **Fatigue lecture** : A le plus court, B le plus long, C compact mais dense
- **Justification du 30 min RDV** : seul C détaille ce qu'on fait pendant les 30 min (différenciateur de pitch)
- **Risque marketing** : C peut paraître trop "landing page commerciale", A reste le plus sobre
