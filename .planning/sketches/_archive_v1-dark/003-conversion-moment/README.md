# Sketch 003 — Conversion moment

## Design Question

Les sections précédentes ont fait le travail émotionnel. Cette dernière
étape doit convertir : afficher le score global de façon crédible, puis
amener naturellement au CTA Calendly unique.

## How to View

```bash
open .planning/sketches/003-conversion-moment/index.html
```

## Variants

- **A — Activity ring + sticky CTA**
  Gauge circulaire type Apple Activity Ring avec 54 au centre, breakdown
  no-shows vs Google en cards, et CTA noir collé en bas (sticky pill qui
  reste visible tout le temps). Simple, propre, un peu "dashboard".

- **B — Compte-rendu médical avec Rx**
  La section entière est stylisée comme un compte-rendu médical officiel
  (header avec tampon "PerfIAmatic Audit v2", "Diagnostic", "Observations
  cliniques", "Prescription" préfixée "Rx ·"). Le CTA est la prescription
  du rapport. Maximum cohérence avec la direction Apple Health / clinique.
  Risque : peut paraître gadget.

- **C — Timeline récap des 5 sections + verdict final**
  Avant le CTA, on rappelle les 5 chiffres clés du rapport sous forme de
  timeline verticale (42 380 € / jeudi 38% / +0,8pt/mois / 14,2% / 54/100),
  puis verdict card noir avec le chiffre répété et le CTA. Le praticien
  "pèse" l'info complète avant de cliquer — boost de conversion par
  accumulation cognitive.

## What to Look For

- **Crédibilité du score** : ring Apple (A) vs stamped report (B) vs rappel exhaustif (C) — lequel inspire le plus confiance dans le chiffre 54/100 ?
- **Timing du CTA** : toujours visible (A sticky) vs intégré au diagnostic (B inline) vs après récap complet (C final)
- **Cohérence avec direction Apple Health clinique** : B > C > A
- **Risque fatigue** : C est le plus long (timeline de 5 items + verdict), mais c'est aussi le plus "argumenté"
- **Reassurance autour du CTA** : C a les micro-signaux (⏱ 🔒 📎), A et B sont plus nus
- **Combinabilité** : on peut envisager A pour l'affichage du score + C pour la timeline récap si on veut les deux
