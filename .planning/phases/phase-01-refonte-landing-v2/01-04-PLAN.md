RSC (no `"use client"`). Section id `faq`. 4 questions, each in its own `<details>` card `rounded-xl` border gray-200. Open state: `open:bg-emerald-50 open:border-emerald-100`. Chevron uses `group-open:rotate-180` — Tailwind's `open:` variant + `group-open:` variant handle it without JS. `<summary>` gets `cursor-pointer list-none` and `::-webkit-details-marker { display: none }` via a utility class (or Tailwind `[&::-webkit-details-marker]:hidden` arbitrary selector).

```tsx
// components/landing/FAQCards.tsx
// RSC — native <details>, no React state, no JS, a11y built-in.

import { ChevronDown } from "lucide-react";

const FAQ: { q: string; a: string }[] = [
  {
    q: "Mes données CSV sont-elles stockées quelque part ?",
    a: "Non. Le fichier est analysé à la volée et supprimé immédiatement après la génération du rapport. Aucune donnée patient n'est conservée.",
  },
  {
    q: "Quel format de CSV est accepté ?",
    a: "L'export standard Doctolib (rendez-vous avec statut). Les autres PMS sont supportés si les colonnes date / statut / praticien sont présentes.",
  },
  {
    q: "Combien de temps prend l'audit ?",
    a: "En moyenne 60 secondes. Le traitement IA du rapport texte peut prendre jusqu'à 90 secondes pour les gros fichiers.",
  },
  {
    q: "L'audit est-il vraiment gratuit ?",
    a: "Oui. Vous obtenez votre diagnostic complet sans inscription et sans carte bancaire.",
  },
];

export default function FAQCards() {
  return (
    <section id="faq" className="mx-auto max-w-4xl px-6 py-20">
      <p className="text-sm font-medium text-accentGreen">FAQ</p>
      <h2 className="mt-2 font-serif text-3xl text-slate-900 md:text-4xl">Les questions qu'on nous pose le plus souvent.</h2>

      <div className="mt-10 space-y-3">
        {FAQ.map(({ q, a }) => (
          <details
            key={q}
            className="group rounded-xl border border-gray-200 bg-white open:bg-emerald-50 open:border-emerald-100 transition-colors"
          >
            <summary className="flex cursor-pointer list-none items-center justify-between gap-4 px-5 py-4 text-left text-slate-900 [&::-webkit-details-marker]:hidden">
              <span className="font-medium">{q}</span>
              <ChevronDown
                aria-hidden
                className="h-5 w-5 flex-none text-slate-500 transition-transform duration-200 group-open:rotate-180"
              />
            </summary>
            <div className="px-5 pb-5 text-sm text-slate-700">{a}</div>
          </details>
        ))}
      </div>
    </section>
  );
}
```

Notes:
- `open:bg-emerald-50` uses Tailwind's `open` variant (available in Tailwind 3.4+, confirmed by package.json ^3.4.15).
- `group-open:rotate-180` rotates the chevron when the parent `<details group>` is open.
- `[&::-webkit-details-marker]:hidden` removes the default disclosure triangle in WebKit browsers; Firefox does not render one by default.
- No `aria-expanded` manual sync needed — native `<details>` handles this for screen readers.
