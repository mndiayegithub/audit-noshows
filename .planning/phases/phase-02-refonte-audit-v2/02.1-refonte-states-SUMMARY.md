# 02.1 — Refonte états audit (formulaire / loading / erreur)

Gap-closure hors-plan post phase-2 : alignement visuel des 3 états non-résultats de `app/audit/page.tsx` sur la DA clinique-claire v2 (déjà appliquée à la landing et au dashboard résultats).

## Changements
- Fond global `bg-background` → `bg-gray-50`.
- Card formulaire, loading, erreur : `rounded-3xl shadow-soft border-slate-100` → `rounded-2xl border border-gray-200 shadow-sm`.
- Titres `font-heading font-extrabold` → `font-serif` (Fraunces) avec `leading-[1.1] tracking-tight` — cohérent avec `LandingHero`.
- Badge "Analyse gratuite" : `bg-primary/10 text-primary` → `bg-emerald-50 text-emerald-700` (style pilule landing).
- Micro-steps : couleurs ad-hoc (`text-accent`, `text-success`) → tokens KPI pastels (`kpiVolume`, `kpiSignal`, `kpiTaux`).
- Dropzone hover : `bg-primary/[0.06]` → `bg-emerald-50/40`, bordure active `border-primary` → `border-primaryDark`.
- CTA primaire : `bg-primary btn-glow rounded-full py-4 font-bold text-lg shadow-lg` → `bg-primaryDark rounded-full py-3 text-sm font-semibold hover:shadow-cta` (flat, cohérent CTABand).
- Loading progress bar : `bg-gradient-to-r from-primary to-accent` → `bg-primaryDark` uni, cocher ✓ en `bg-kpiSignal text-kpiSignal-fg`.
- Erreur : carte rouge lourde (`bg-danger/10` + icône 64px) → carte blanche neutre, icône 48px `bg-red-50 border-red-200 text-red-600`, CTA primaire `bg-primaryDark` + secondaire `border-gray-200`.
